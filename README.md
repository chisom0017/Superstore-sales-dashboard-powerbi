# 📊 Superstore Sales Performance Dashboard

## 📌 Project Overview

This project presents an interactive sales performance dashboard built using **Microsoft Power BI** and the **Superstore Sales Dataset**.

The dashboard provides insights into sales, profit, quantity sold, and order performance, helping stakeholders make informed business decisions.

---

## 🛠️ Tools Used

- Microsoft Power BI

---

## 📂 Dataset

- Superstore Sales Dataset

---

## 📈 Key Performance Indicators (KPIs)

- 💰 Total Sales: 2.30M
- 📈 Total Profit: 286.40K
- 📦 Total Quantity Sold: 38K
- 🛒 Total Orders: 5,009

---

## 🔍 Key Insights

- Technology recorded the highest sales.
- West region generated the highest profit.
- Consumer segment contributed the largest share of total sales.
- Monthly sales increased toward the end of the year.

---

## 💡 Recommendations

- Increase investment in the Technology category.
- Improve performance in lower-performing regions.
- Monitor KPIs regularly.
- Use interactive dashboards to support business decisions.
